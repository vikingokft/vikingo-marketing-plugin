# Csatorna-specifikus elemzési szempontok

A Fázis 1 elemzésében minden csatorna-típushoz külön mélyítés. Az általános 8 dimenzió + szókincs + szerkezet MELLETT, ezek kiegészítések. A zárójeles referencia-számok a cég `00-agy/brand/markahang.md`-jéből jönnek — ahol nincs adat, mérd be a mintákból.

## Email

| Szempont | Mit keress |
|---|---|
| **Tárgysor** | Hossz, típus (kérdés / ütős / provokatív / személyes), kisbetű-e |
| **Hook** | Köszönéssel nyit? (gyakran TILOS Cég-módban). Mi az első mondat típusa? |
| **Hossz** | Karakterszám (cég email átlag: [X] karakter) |
| **Bekezdés** | 1 soros dominál? Légies? |
| **CTA** | Agresszív vagy felelősségátadó? |
| **Zárlat** | „Üdv, [oktató/cég-hang]" típus, vagy más? |
| **Ui.:** | Van-e? Milyen arányban használja a cég? |

## Hirdetés-videó / videoszkript

| Szempont | Mit keress |
|---|---|
| **Hook (0-5 mp)** | Milyen típus? (kijelentés / bevallás / lépcsőzetes / szám / provokatív) |
| **Időzítés** | 30-120 mp? Vagy hosszabb? |
| **Beszélt nyelv** | Rövid mondatok, szünetek, „De" mint ritmusképző |
| **CTA típus** | Milyen lezárás? |
| **Felvételi mód** | Kamerába beszél? Narráció? Screencast? |

## Edukáció (lecke, tananyag)

| Szempont | Mit keress |
|---|---|
| **Leckenyitás** | Típus? (pl. belekezdés [X]%, kérdés [X]%, üdvözlés [X]%) |
| **„Mi" vs „Én" vs „Te"** | Screencast → „mi"; koncepcionális → „te"/„én" |
| **Fogalommagyarázat** | Van-e egyszerűsítés? Hasonlat? |
| **Bátorítás** | Cég-átlag: [X]/1000 szó. Természetes, nem túlzó? |
| **Átvezetés** | Leckék és szekciók között hogyan vezet át? |

## Sales-oldal

| Szempont | Mit keress |
|---|---|
| **Hero** | Termék/kurzusnév + alcím + leírás + 3 adat formátum? |
| **Social proof** | Pozíció (pl. hero után a domináns) |
| **Kinek való** | Persona-alapú? H3-ak alatt kifejtéssel? |
| **CTA stílus** | Nyomás nélküli, biztonságérzet (pl. próbaidő)? |
| **Tekintély** | Számok, tények, ügyfél-lista (nem sebezhetőség!) |

## Social

Ha a cég `00-agy/brand/markahang.md`-je **nem** tartalmaz Social szekciót, Külső módban a 2.5 alfejezetbe kerül. Cég-módban két opció:

1. **Új III. Social szekció létrehozása** — ha a felhasználó jóváhagyja
2. **Átadás a `social-tartalom-tervezo` skillnek** — Fázis 1 outputja kontextus lesz

| Szempont | Mit keress |
|---|---|
| **Poszt-típus** | Sztori / oktatás / inspiráció / heti rituálé / launch? |
| **Hossz** | Karakter / mondat-szám |
| **Hashtag-stratégia** | Van-e? Hányat? Hol? |
| **Platform-illeszkedés** | Facebook vs. Instagram vs. YouTube — szövegminta különbözik-e? |
| **Komment/válasz stílus** | Hogyan reagál a kommentekre? (ha van adat) |
| **Nyitó / záró formulák** | Tipikus indítások és lezárások |
