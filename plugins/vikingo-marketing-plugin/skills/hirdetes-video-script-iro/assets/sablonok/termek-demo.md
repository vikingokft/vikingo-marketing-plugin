### VS-021: Egyszerű Prompt Demo
- **Típus**: product-demo
- **Hossz**: short
- **Ajánlott**: SaaS
- **Hook**: „Ez az egyetlen mondat, amit beírtam: '[prompt szó szerint]'. Ezt kaptam vissza:"
- **Body**: „[Képernyőfelvétel / generált eredmény bemutatása]. [Narráció]: Nem kellett [hagyományos módszer 1], nem kellett [hagyományos módszer 2]. Egy prompt, [X másodperc], és kész. [Összehasonlítás — pl. 'Ugyanez korábban [Y óra/nap] volt']. [Második példa prompt → eredmény — gyors vágás]."
- **CTA**: „Próbáld ki magad: [link]. [Ajánlat, pl. 'Ingyenes [X] kredit az induláshoz.']"
- **Példa brand**: Sora / Runway
- **Megjegyzés**: A „prompt → wow eredmény" szekvencia bűvésztrükk-hatású — a néző azonnali „én is akarom" érzést kap.
