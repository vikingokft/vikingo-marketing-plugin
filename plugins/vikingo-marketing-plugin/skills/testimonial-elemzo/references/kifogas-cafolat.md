# Kifogás-cáfolat + fejlesztési feedback + videó-testimonial

## Kifogás-cáfolat mátrix

A testimonialok leg-értékesebb marketing-felhasználása: élő bizonyítékkal cáfolják a vásárlási kifogásokat.

| Kifogás | Milyen testimonial cáfolja | Példa-idézet |
|---|---|---|
| **„Túl drága"** | Aki ROI-t ért el (ügyfelek, bevétel) | „Az első hónapban visszahozta az árát" |
| **„Nincs időm"** | Aki kevés idővel is haladt | „Gyerek mellett, este 30 percben tanultam" |
| **„Nem vagyok technikai"** | Aki nulláról indult | „Sosem csináltam ilyet, mégis sikerült" |
| **„Már próbáltam, nem működött"** | Aki máshol nem tudott | „Máshol elakadtam, itt végigcsináltam" |
| **„Ki ez az ember?"** | Aki [a céged hangját / az oktatót] dicséri | „Úgy magyaráz, mintha barátom lenne" |
| **„Nem tudom melyiket válasszam"** | Aki segítséget kapott a választáshoz | „Megmutatta, melyik utat válasszam" |

A termék `kifogasok.md`-jéhez rendeld hozzá a testimonialokat: minden kifogáshoz legyen 2-3 bizonyíték. Ha a `kifogasok.md` még `KITÖLTENDŐ`, dolgozz a fenti mátrix alap-kifogásaiból, és jelezd, hogy a kifogás-lista a `termek-specialista`-val vagy a `celcsoport-elemzo`-vel élesíthető.

## Fejlesztési feedback kategóriák

A testimonial nemcsak marketing — visszajelzés is. A kategorizálás segít a fejlesztési listához.

| Kategória | Mit keress | Példa | Akció-típus |
|---|---|---|---|
| **Termék** | Tartalom-minőség, aktualitás, mélység | „Ez a rész elavult" | Termék-frissítés |
| **Oktatás** | Tanítási stílus, érthetőség, tempó | „Túl gyorsan haladt" | Tartalom-szerkesztés |
| **Platform** | UX, navigáció, technikai működés | „Nem találom a mellékleteket" | Fejlesztés |
| **Közösség** | Fórum, támogatás, interakció | „Kevés az aktív válaszolás" | Közösség-menedzsment |
| **Eszközök** | Mellékletek, sablonok, bővítmények | „A sablon nem kompatibilis" | Eszköz-frissítés |
| **Struktúra** | Felépítés, sorrend, haladás | „Nem volt egyértelmű a sorrend" | Restructuring |

## Fejlesztési prioritás

| Prioritás | Kritérium |
|---|---|
| **P1: Kritikus** | Több ember jelzi + akadályozza a haladást |
| **P2: Fontos** | Több ember jelzi + rontja az élményt |
| **P3: Nice-to-have** | Egyedi kérés + kis hatás |

## Videó-testimonial elemzés

A videó testimonialok extra értéket hordoznak:
- **Hitelesebb** (arc, hang, érzelem)
- **Használható hirdetésben** (UGC = Felhasználó Generated Content)
- **Erősebb social proof**

### Extra elemzési szempontok videónál

| Szempont | Mit keress |
|---|---|
| **Érzelem** | Milyen arckifejezés, hangszín? Hol érzékelhető? |
| **Legjobb 15 mp** | Melyik 15 másodperc a legerősebb? (hirdetés-clip) |
| **Kulcs-mondat** | Milyen mondatot lehetne szövegesen is használni? |
| **Hook-potenciál** | Az elejéből készíthető-e hirdetés-hook? |
| **Platform** | Hol lenne legerősebb: FB / IG / YouTube / TikTok? |

Az átirat-alapú elemzés mellett a vizuális minőséget is jelöld (jó kép / rossz fény / zaj / kép-stabilitás).
