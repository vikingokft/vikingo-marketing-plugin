# Testimonial-elemzés sablon (Single mód)

A Single mód Fázis 2 outputja. Ezt a struktúrát illeszd be a `testimonialok.md` megfelelő szekciójába.

> Stílus-szabály a kitöltéskor: a saját szövegedben tilos a gondolatjel (— vagy –) mondat közben és listacímke-elválasztóként. Használj kettőspontot, vesszőt vagy két mondatot. A szó szerinti ügyfél-idézetet (`Idézet` blokk) ne írd át. Valós forrás híján ne tölts ki kitalált idézetet vagy számot — jelöld „[becsült, megerősítendő]" vagy hagyd üresen.

```markdown
## {{Ügyfél neve}} ({{# entry-szám}})

**Termék:** {{termék / szolgáltatás}}
**Forrás:** {{exit-kérdőív / onboarding-kérdőív / email / komment / videó-átirat}}
**Dátum:** {{dátum}}

### Idézet (szó szerinti)

> „{{idézet}}"

### Típus + erősség

- **Típus:** {{eredmény-alapú / érzelmi / skill-specifikus / before-after / sztoris}}
- **Erősség:** {{⭐⭐⭐⭐⭐ → ⭐}}
- **Arc / fotó:** {{igen / nem}}
- **Sales-readiness:** {{A / B / C}}

### Avatar-kapcsolás

- **Elsődleges avatar:** {{melyik avatar}}
- **Másodlagos avatar(ok):** {{ha több illeszkedik}}
- **Indoklás:** {{1-2 mondat: foglalkozás / motiváció / probléma / eredmény / élethelyzet alapján}}

### Marketing-felhasználási helyek

- **Sales-oldal hero:** {{igen / nem / kontextus}}
- **Sales-oldal social proof:** {{igen / nem}}
- **Kifogás-cáfolat:** {{melyik kifogást — ár / idő / képesség / bizalom / hitelesség}}
- **Email-nyitás:** {{igen / nem — milyen email-típushoz}}
- **Hirdetés-hook:** {{igen / nem — melyik platform}}
- **Social-poszt:** {{igen / nem — milyen platform}}
- **Webinár:** {{igen / nem}}

### Marketing-üzenet konverzió

> {{a testimonial-ból kinyerhető konkrét marketing-üzenet — pl. headline-javaslat}}

### Fejlesztési tanulság (ha van)

- **Kategória:** {{termék / oktatás / platform / közösség / eszközök / struktúra}}
- **Prioritás:** {{P1 / P2 / P3}}
- **Konkrét javaslat:** {{mit kell csinálni}}

### Megjegyzés

{{Esetleges kontextus, ami a feldolgozáshoz fontos}}
```
