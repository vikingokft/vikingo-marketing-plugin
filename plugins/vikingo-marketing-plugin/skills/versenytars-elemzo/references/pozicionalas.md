# Saját pozicionálás vs. versenytárs

A Fázis 3 összehasonlításhoz. Itt vannak a fő dimenziók és kategóriák, amikkel a saját ajánlatot össze tudod hasonlítani a versenytárssal.

## Saját-ajánlat vs. versenytárs mátrix

Az összehasonlításhoz használt 10 dimenzió (igazítsd a saját iparágadhoz — ezek egy online oktatási/előfizetéses ajánlatra példák, de a logika bármely termékre átültethető):

| Dimenzió | Kérdés |
|---|---|
| **Ár/érték** | Mennyibe kerül? Mit kap érte? Melyik a jobb deal? |
| **Terjedelem** | Mennyi tartalom / mekkora kínálat? Milyen szélességben fed le? |
| **Közösség** | Van-e közösségi elem? Mennyire aktív? |
| **Útvonal** | Van-e strukturált használati/tanulási útvonal? |
| **Eszközök** | Járnak-e extra eszközök/bővítmények? |
| **Gyakorlatiasság** | Mennyire hands-on? Van-e kihívás, feladat, sablon? |
| **Gamifikáció** | Van-e motivációs rendszer? |
| **Hangnem** | Milyen a kommunikáció? Barát / guru / corporate? |
| **Tölcsér** | Milyen marketing-rendszert futtat? |
| **Hitelesség** | Milyen bizonyítékok vannak? (testimonial, eredmények) |

## Piac-sajátosságok (igazítsd a saját piacodhoz)

Minden piacnak megvan a maga vásárlói-pszichológiája. Az alábbi sorok egy lokális online-oktatási piacra példák — cseréld le a SAJÁT iparágad sajátosságaira:

| Sajátosság | Jelentés |
|---|---|
| **Fizetési hajlandóság** | Mennyire elfogadott a fizetős termék? Mi az ingyenes-elvárás? |
| **Bizalomhiány** | Mennyire erős a „ki ez az ember/cég?" faktor? |
| **Brand-dominancia** | A személyes brand vagy a cég/platform a fontosabb? |
| **Csatorna-fókusz** | Hol történik a legtöbb marketing/közösség? (FB / IG / LinkedIn / YouTube) |
| **Ár-érzékenység** | Mi az elfogadott árkategória, hol kezd nehéz lenni? |

## Versenytárs-kategóriák (példa-keretrendszer)

Sorold a versenytársat valamelyik kategóriába, és fogalmazd meg, hogyan pozicionálsz vele szemben. Az alábbi sorok egy oktatási-piac-példa — alakítsd a saját iparágad kategóriáira:

| Kategória | Jellemző | Hogyan pozicionálunk velük szemben |
|---|---|---|
| **Egy-termékes szereplők** | Egy termék, magas ár | Mi: rendszer/előfizetés, nem egyszeri vásárlás. Ár/érték-előny |
| **Előfizetéses platformok** | Hasonló modell | Mi: lokalitás, közösség, gyakorlatiasság, [saját differenciátor] |
| **Prémium mentorok** | 1:1 vagy small-group, magas ár | Mi: DIY + közösség, elérhetőbb ár |
| **Intenzív programok** | Drága, garanciás | Mi: rugalmasság, alacsonyabb belépő, szélesebb skála |
| **Ingyenes tartalom** | YouTube, blog, közösségi média | Mi: rendszer, útvonal, közösség, [amit az ingyenes nem ad] |

## Stratégiai kérdések az elemzésnél

A Fázis 3 végén ezeket válaszold meg:

1. **Hol pozicionáljuk magunkat ehhez a versenytárshoz képest?**
2. **Mit kommunikálunk jobban náluk?** → Erősítjük
3. **Mit nem kommunikálunk, de kellene?** → Pótoljuk
4. **Mit csinálnak jobban?** → Tanuljunk belőle
5. **Hol vannak fehér foltjaik?** → Lehet stratégiai irány nekünk

## Mit ne csinálj a pozicionálásban

- ❌ **Direkt összehasonlítás a saját marketingben** — ne mondj „X-nél jobbak vagyunk". Inkább pozicionálj a saját értékeid mellett.
- ❌ **Versenytárs lebecsmérlése** — operatív tanulság igen, publikus üzenet nem.
- ❌ **Másolás** — adaptáció igen, másolás nem. Mindig a saját szókinccsel (a cég-hang szerint — ha van `00-agy/brand/markahang.md`, abból).
