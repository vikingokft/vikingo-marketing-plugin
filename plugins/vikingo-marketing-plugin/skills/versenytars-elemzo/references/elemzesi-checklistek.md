# Elemzési checklist-ek (weboldal / social / hirdetés)

## Weboldal — Sales / Landing oldal

| Elem | Mit keress | Miért fontos |
|---|---|---|
| **Headline** | Mi az első mondat? Milyen ígéret? | Ez a fő üzenet, ezt kommunikálják legjobban |
| **Subheadline** | Hogyan támasztja alá? | Második szintű messaging |
| **Hero szekció** | Vizuális + szöveg együtt | Első benyomás 3 mp-en belül |
| **Probléma szekció** | Milyen fájdalmat szólít meg? | Azonosulás-építés, szókészlet |
| **Megoldás szekció** | Hogyan pozicionálja a terméket? | USP és differenciátor kommunikáció |
| **Funkciók / előnyök** | Listázzák? Funkció vagy előny? | Funkciók vs. előnyök arány |
| **Social proof** | Testimonialok, logók, számok? | Bizalom-építés módja |
| **Árazás** | Hogyan keretezi az árat? | Ár-érték pozicionálás-stratégia |
| **CTA** | Hány CTA van? Milyen szöveg? Hol? | Cselekvésre ösztönzés |
| **Garancia** | Van-e? Milyen típusú? | Kockázatcsökkentés |
| **FAQ** | Milyen kérdéseket kezelnek? | Célcsoport kifogásai |
| **Footer CTA** | Hogyan zár? | Utolsó meggyőzési kísérlet |

## Weboldal — About / Rólunk oldal

| Elem | Mit keress |
|---|---|
| **Alapító-sztori** | Van-e? Milyen narratíva? (zero-to-hero, passion-driven, pain-driven) |
| **Értékek** | Explicit értékek kommunikálása |
| **Csapat** | Egyéni brand vagy csapat? |
| **Eredmények** | Számok, díjak, média |
| **Küldetés** | Van-e misszió/vízió-statement? |

## Social media — Profil elemzés

| Elem | Mit keress |
|---|---|
| **Bio** | Mi a fő üzenet? Milyen pozicionálás? |
| **Link** | Hova irányít? (weboldal, tölcsér, linktree) |
| **Highlight / Pinned** | Mi a legfontosabb számukra? |
| **Követők** | Szám + növekedés (ha elérhető) |

## Social media — Tartalom (5-10 poszt)

| Elem | Mit keress |
|---|---|
| **Tartalom-típusok** | Tanító / szórakoztató / promóciós / személyes, milyen arányban? |
| **Formátum** | Kép / videó / carousel / reels / szöveg |
| **Hangnem** | Barátságos / szakmai / provokatív / humoros |
| **Engagement** | Like, komment, share arányok, mi működik? |
| **Hashtag-stratégia** | Használ? Milyen típusúak? |
| **Közvetlen értékesítés** | Milyen gyakran promótál? Milyen CTA-kat? |
| **Közösségi interakció** | Válaszol-e a kommentekre? Milyen stílusban? |

**A legfontosabb kérdés social-nál:** **Melyik poszt kapja a legtöbb engagement-et?** → Ez mutatja milyen üzenet rezonál a közönségükkel.

## Hirdetés — Meta Ad Library

- URL: `facebook.com/ads/library`
- Keress a versenytárs nevére vagy oldalára
- Szűrj: ország, platform, aktív hirdetések

## Hirdetés — szempontok

| Elem | Mit keress |
|---|---|
| **Hook** | Mi az első mondat / első 3 mp? Milyen hook-típus? |
| **Kreatív-típus** | Kép / videó / carousel, melyiket használja legtöbbet? |
| **Angle** | Milyen szögből közelíti meg? (probléma, eredmény, sztori, vélemény, provokáció) |
| **CTA** | „Több info" / „Regisztrálj" / „Vásárolj"? |
| **Landing** | Hova vezet? (sales / landing / webinár regisztráció) |
| **Szöveg-hossz** | Rövid (1-2 mondat) vagy hosszú (bekezdések)? |
| **Mennyi hirdetés fut?** | Kevés (1-3) → teszteli / Sok (10+) → skálázza |
| **Meddig futnak?** | Rövid ideje → tesztel / Hosszú ideje → nyerő hirdetés |

## Hook-típusok felismerése

| Típus | Példa | Mikor használják |
|---|---|---|
| **Kérdés** | „Tudtad, hogy...?" | Kíváncsiság-keltés |
| **Állítás** | „A legtöbb ember rosszul csinálja" | Provokáció, figyelemfelkeltés |
| **Sztori** | „Tavaly még..." | Azonosulás, empátia |
| **Eredmény** | „[konkrét eredmény] a 3. hónapban" | Social proof, vágy |
| **Kontrasztos** | „Nem kell hozzá [tipikus akadály]" | Meglepetés, akadály-eltávolítás |
| **Direkt ígéret** | „Megtanítom 30 nap alatt" | Egyszerűség, konkrétum |

## „Fehér folt" elemzés

A fehér folt az, amit a versenytárs NEM csinál, de a célcsoport igényelné. Kérdezd:

- Milyen problémát nem old meg?
- Milyen célcsoport-szegmenst hagy ki?
- Milyen formátumban nem kommunikál?
- Milyen árkategóriát nem fed le?
- Milyen témát nem fed le / nem tanít?

Ezeket emeld be a 2G. Tanulságok szekcióba mint potenciális saját irányokat.
