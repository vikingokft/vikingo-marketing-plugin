# Márkahang-keretrendszer (a 13. szekcióhoz)

A Brand Guide 13. szekciója a márkahang. A teljes, mérésen alapuló hang-profilt (8 dimenzió szövegmintából, szókincs, ritmus) a **`markahang-elemzo` skill** adja — ha van mért eredmény, azt emeld be, ne találd ki.

Ezt a referenciát csak akkor használd, ha **nincs** külön márkahang-elemzés, és a guide-on belül kell egy rövidített profilt felvenni. Ekkor a 9 alszekciót töltsd ki az alábbi keretrendszerrel.

---

## Tartalom

1. 9 alszekció (megszólaló → egy mondat)
2. 12 brand-archetípus
3. 4 tengelyes érzelmi tónus-skála

---

## 9 alszekció

**13.1 Megszólaló** — Ki beszél? Egy ember (ki, milyen szerepben) / a márka mint „mi" / vegyes.
**13.2 Nézőpont** — Többnyire „én" (személyes, alapító-hang) / „mi" (csapat) / semleges („a márka...").
**13.3 Megszólítás** — Tegezés / magázás / többes / kevert (kevertnél: hol melyik).
**13.4 Szókincs, stílus, érthetőség:**
- Stílus iránya: köznyelvi / szakmai / egyszerű / laza-szlenges / humoros / elegáns / kevert
- Szakzsargon: kerüli (lefordítja) / ritkán / bátran (célcsoport érti)
- Jellemző szavak/kifejezések („nagyon én vagyok") + kerülendő szavak
- Érthetőség: nagyon egyszerű / közérthető / szakmailag igényes de világos / összetett
- Mondatszerkezet: rövid-pattogós / kiegyensúlyozott / hosszabb-magyarázó / dinamikusan váltakozó
**13.5 Személyesség** — Kapcsolati viszony (barát / mentor / szakértő / vezető / gondoskodó / szórakoztató) + mennyit mutat magából (tárgyilagos / közepes / erősen személyes).
**13.6 Érzelmi dimenziók** — 1-3 archetípus + 4 tengelyes tónus-skála (lásd lent).
**13.7 Képiség** — Metaforák (gyakran / ritkán / kerüli) · érzékszervi nyelv (vizuális / tapintás / hang / íz-illat) · képi világok (sport, utazás, tech, természet...).
**13.8 Ritmus és tempó** — Alapritmus (pörgős / nyugodt / váltakozó / mesélős) · íráskép (üres tér, rövid bekezdések, kiemelések, felsorolások) · központozás · emoji (soha / ritkán / platformfüggő / rendszeresen).
**13.9 A márkahang egy mondatban** — Tömör összefoglaló.

## 12 brand-archetípus (válassz 1-3-at)

1. **Gondoskodó** — segítő, védelmező. „Segítek, gondoskodom."
2. **Bölcs** — tanító, tudásközpontú. „Tudással világítok."
3. **Felfedező** — kalandvágyó, szabadságkereső. „Felfedezem az ismeretlent."
4. **Hős** — bátor, kitartó. „Legyőzöm az akadályokat."
5. **Lázadó** — szabálytörő, provokatív. „Más utat járok."
6. **Alkotó** — kreatív, vizionárius. „Létrehozok, megalkotok."
7. **Bohóc** — szórakoztató, könnyed. „Mosolyt fakasztok."
8. **Átlagember** — megbízható, földhözragadt. „Olyan vagyok, mint te."
9. **Szerető** — szenvedélyes, esztétikai. „Szeretem, amit csinálok."
10. **Uralkodó** — irányító, strukturált. „Rendet teremtek."
11. **Varázsló** — átformáló. „Megváltoztatom a valóságot."
12. **Ártatlan** — optimista, őszinte. „Mindenben a jót látom."
